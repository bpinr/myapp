# 🎯 Игра «Угадай число»

Консольная игра на Go, в которой игрок должен угадать случайное число за ограниченное количество попыток.

Проект реализован в рамках учебного задания по изучению основ Go: функций, циклов, условий, срезов, обработки ошибок, работы с файлами и JSON.

## 🎮 Возможности

* 🎲 Генерация случайного числа.
* 🎚️ Три уровня сложности.
* 🔢 Ограниченное количество попыток.
* ❌ Проверка корректности введённого числа.
* 🔥 Подсказки по расстоянию до загаданного числа:

  * 🔥 Горячо — разница не более 5.
  * 🙂 Тепло — разница не более 15.
  * ❄️ Холодно — разница больше 15.
* 📝 Сохранение всех попыток игрока.
* 🎨 Цветные сообщения в терминале.
* 🔄 Возможность сыграть несколько раундов без перезапуска программы.
* 💾 Сохранение результатов игры в `results.json`.

## 🎚️ Уровни сложности

| Уровень   | Диапазон | Попытки |
| --------- | -------: | ------: |
| 🟢 Easy   |     1–50 |      15 |
| 🟡 Medium |    1–100 |      10 |
| 🔴 Hard   |    1–200 |       5 |

## 💾 Сохранение результатов

После каждого завершённого раунда результат сохраняется в файл:

```text
results.json
```

В файл записываются:

* дата и время игры;
* результат — победа или проигрыш;
* количество использованных попыток.

Пример:

```json
{"date":"2026-09-23 17:30:12","result":"win","attempts":4}
{"date":"2026-09-23 17:35:41","result":"lose","attempts":10}
```

Файл `results.json` создаётся автоматически после первой завершённой игры.

## 🧩 Основные функции

### `parseNumber()`

Преобразует введённую строку в целое число и возвращает ошибку, если введено некорректное значение.

```go
func parseNumber(input string) (int, error)
```

### `hint()`

Определяет уровень близости введённого числа к загаданному.

```go
func hint(z int, num int)
```

### `difficult()`

Определяет выбранный уровень сложности и запускает соответствующую игру.

```go
func difficult(a *int) (int, error)
```

### `playGame()`

Основная игровая функция. Получает максимальное число, количество попыток и номер сложности.

```go
func playGame(maxNumber int, maxAttempts int, level int)
```

Например:

```go
playGame(50, 15, 1)
```

### `SaveResult()`

Сохраняет результат завершённой игры в `results.json`.

```go
func SaveResult(result string, attempts int)
```
