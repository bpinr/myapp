# 🎯 Игра «Угадай число»

Консольная игра на Go, где нужно угадать случайное число за ограниченное количество попыток.

## Возможности

* 🎚️ 3 уровня сложности
* 🔢 Ограниченное количество попыток
* 🔥 Подсказки: горячо / тепло / холодно
* 💾 Сохранение результатов в `results.json`
* 🔄 Возможность начать новую игру

## Требования

* Go **1.27.1**
* Git

## Запуск

```bash
git clone https://github.com/bpinr/myapp.git
cd myapp
go run .
```

## Уровни сложности

| Уровень   | Диапазон | Попытки |
| --------- | -------: | ------: |
| 🟢 Easy   |     1–50 |      15 |
| 🟡 Medium |    1–100 |      10 |
| 🔴 Hard   |    1–200 |       5 |
